# VIP Lab for Loon

一个面向 Loon 的轻量平台连通性检测插件。

## 安装

在 Loon 中添加插件 URL：

`https://raw.githubusercontent.com/ashun520/loon-rules/main/VIPLab/VIPLab.plugin`

## 使用

1. 添加插件后打开插件参数。
2. 可修改爱奇艺、腾讯视频、优酷、美图官网的检测地址。
3. 选择单次超时时间。
4. 在插件操作中手动运行「检测视频与美图平台」。
5. 查看 Loon 通知和脚本日志中的 HTTP 状态、响应耗时。

## 当前版本能力

- 对配置的 HTTP/HTTPS 地址发起 GET 请求。
- 显示 HTTP 状态码与响应耗时。
- 对请求错误、4xx、5xx 做初步分类。
- 将最近一次检测结果保存在 Loon 本地持久化存储中。
- 手动运行，不默认后台定时请求。

## 重要限制

- 这是平台官网/自定义地址的网络连通性检测，不是实际视频播放测速。
- HTTP 200 不代表账号有 VIP，也不代表付费视频可播放。
- HTTP 403/404 也不必然代表线路失效，可能是站点风控、地区限制或页面策略。
- 不读取账号密码、Cookie 或应用私有数据；不破解会员、不绕过 DRM、付费验证或访问控制。
- 美图会员权益分析需要以美图官方公开说明或用户主动提供的会员页面信息为依据，Loon 插件本身无法直接读取 App 内的会员身份。

## 兼容性

使用 Loon 3.5.1 (983) 及以上的新 Script 语法。
